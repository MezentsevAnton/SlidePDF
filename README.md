# SlidePDF

Простой конвертер PPT и PPTX в PDF для Windows с тёмным интерфейсом.

**PowerPoint и отдельная установка LibreOffice не нужны.** В готовый ZIP включён LibreOffice 26.2.7. Конвертация выполняется локально; приложение не загружает презентации на сервер.

## Запуск

1. Скачайте `SlidePDF-0.2.1-lite-win-x64.zip` из Releases на GitHub или получите архив от автора.
2. Полностью распакуйте архив.
3. Откройте `SlidePDF.exe` в распакованной папке `SlidePDF`.
4. Добавьте файлы кнопкой или перетаскиванием, выберите папку и нажмите «Конвертировать в PDF».

Передавайте друзьям **весь архив**, а не только EXE. Папка `runtime` должна оставаться рядом с приложением. Установка Office и права администратора для обычной работы не нужны.

Каждая презентация сохраняется в отдельный PDF. При совпадении имён создаются `Имя (2).pdf`, `Имя (3).pdf` и так далее. Исходные файлы не меняются. При ошибке наведите указатель на строку файла для просмотра подробностей. Остальные файлы продолжают обрабатываться.

## Требования и ограничения

- Windows 10/11 x64, .NET Framework 4.8 (входит в актуальные Windows 10/11).
- Место для распакованного комплекта и временных копий презентаций.
- Оформление сложных слайдов может отличаться от PowerPoint. Для сохранения вида текста нужны шрифты, использованные автором. Шрифты Microsoft в комплект не входят.
- Анимация и видео не воспроизводятся в статическом PDF.
- Защищённые паролем и повреждённые файлы могут не конвертироваться. На один файл отведено до 3 минут.
- Во время обработки закрытие приложения блокируется до завершения очереди.
- Для каждого файла создаётся временный профиль LibreOffice с отключёнными макросами. После обработки временные файлы удаляются; при аварийном завершении могут остаться в `%TEMP%\SlidePDF`.
- EXE не подписан сертификатом издателя; Windows может показать предупреждение при первом запуске скачанного приложения.

## Compact package

This package keeps Russian and English resources, one icon theme, fonts and native conversion libraries. Optional dictionaries, extensions, help, templates, galleries and scripting resources are omitted. Conversion after trimming has not been tested; validate your presentations before distributing this build. The full build remains available separately.
